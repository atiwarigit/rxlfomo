# FOMO Portfolio Dashboard

Live PnL / risk dashboard for fomo.family traders. Pulls FOMO API + on-chain wallet mark-to-market instead of mock data.

## Goals

- See total equity, realized/unrealized PnL, cash buffer, and drawdown in one place
- Size and concentration limits that scale toward $1M+ PnL
- Keep social/influence stats (followers, rank) next to execution stats
- Data that stays current: live APIs + a local daily equity log
