# Product context

Memecoin PnL on FOMO looks great in-app until liquidity vanishes. This dashboard exists so the book is managed with the same discipline as the trading: cash floor, position caps, drawdown response, and an independent wallet check.

The user opens it daily/weekly, refreshes live numbers, and reviews alerts before putting on new risk. The ops floor (hero bags, decision stream, tape) is the daily scan; desk chat is for asking the book questions once an LLM key is attached.
